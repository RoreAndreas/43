Premier cadre de l'accueil : le carrousel de présentation.

Déposez ici les images de votre présentation, une par diapositive. Elles
défilent sur l'accueil, puis en grand quand on ouvre le cadre, avec leur
liste à côté.

  - Depuis PowerPoint : Fichier › Exporter › Changer le type de fichier ›
    PNG, puis « Toutes les diapositives ». Depuis Canva : Partager ›
    Télécharger › PNG. Déposez les images obtenues ici, telles quelles.
  - L'ordre suit les numéros des noms : « Diapositive2 » passe avant
    « Diapositive10 ». Pour le choisir vous-même, commencez le nom par un
    numéro : « 01 - Couverture.png », « 02 - Parcours.png »…
  - Le nom du fichier, sans son numéro, sert de titre dans la liste.
  - Formats : .png, .jpg, .webp. Le format 16:9 des présentations
    s'affiche en entier ; 2 000 px de large suffisent.

Les trois images « (exemple) » ne sont là que pour montrer le carrousel :
supprimez-les quand vous déposerez les vôtres.
